# Adding Temporal to Your Gen-AI Application Tutorial

This repository contains the code that goes along with our [`Creating a Durable Weather-Calling MCP Tool with Temporal`](https://learn.temporal.io/tutorials/ai/building-mcp-tools-with-temporal/introducing-mcp-temporal/) tutorial. Please reference that tutorial to see how to use this repository.

## Prerequisites

- [Claude Desktop](https://www.claude.com/download)
- Python with uv installed
